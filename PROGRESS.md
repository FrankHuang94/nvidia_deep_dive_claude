## How to resume

1. `make setup` (or: `pip install -r requirements.txt && npm ci`; set `PUPPETEER_EXECUTABLE_PATH`
   if Chrome is pre-installed). Also install `graphviz` and `d2` for `make diagrams`.
2. Read the phase table below and continue at the first phase that is not ✅.
3. Each phase ends with: `make charts diagrams build validate` → update this file → commit
   `phase-N: <what> (+X words, +Y visuals)` → `git push origin main` → `git tag phase-N-complete`.
4. Chapter manifest (status, QA) lives in [`docs/manifest.yml`](docs/manifest.yml); the stats table
   below is regenerated by `make build`.
