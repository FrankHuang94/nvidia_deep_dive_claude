## 打印建议

- **纸张与缩放**：A4，选择“实际大小”或 100% 缩放（页边距约 15–17 mm）；可双面打印。
- **彩色或黑白**：图表采用色盲友好配色，建议彩色打印；黑白打印时，部分图表中不同系列的区分度会降低。
- **图表与图注**：数据图表保留英文原版，每张图下方的灰色文字为中文图注，概括该图的结论与关键数字。
- **引用**：正文中的灰色上标（如 S2031）为来源编号，完整书目见卷五附录“参考文献”。
- **数据时效**：截至 2026-11-05。
