## A

- <a id="asic"></a>**ASIC** — Application-specific integrated circuit: a chip designed for one workload. In AI it means custom accelerators such as Google's TPU or AWS Trainium, trading flexibility for efficiency. *See also:* [GPU (graphics processing unit)](#gpu).
## C

- <a id="cowos"></a>**CoWoS** — Chip-on-Wafer-on-Substrate: TSMC's 2.5D advanced packaging that places GPU dies and HBM stacks side by side on a silicon interposer (CoWoS-S) or on bridge-based variants (CoWoS-L, CoWoS-R). Capacity has been a key bottleneck for AI accelerators. *See also:* [HBM (high-bandwidth memory)](#hbm).
- <a id="cuda"></a>**CUDA** — NVIDIA's programming platform (language extensions, compiler, runtime, driver and libraries) launched in 2006 that lets developers run general-purpose code on GPUs. The basis of NVIDIA's software moat. *See also:* [CUDA-X](#cuda-x).
- <a id="cuda-x"></a>**CUDA-X** — NVIDIA's umbrella name for its hundreds of domain libraries built on CUDA (cuBLAS, cuDNN, NCCL, RAPIDS and others). *See also:* [CUDA](#cuda).
## D

- <a id="data-center-segment"></a>**Data center (NVIDIA segment)** — NVIDIA's reporting segment for AI and HPC products sold into datacenters, split into compute (GPUs, systems) and networking (NVLink, InfiniBand, Ethernet, NICs, DPUs).
- <a id="die"></a>**Die** — A single piece of silicon cut from a wafer. Modern AI GPUs such as Blackwell put two (and Rubin Ultra four) compute dies in one package. *See also:* [GPU (graphics processing unit)](#gpu), [Reticle limit](#reticle-limit).
## F

- <a id="flops"></a>**FLOPS** — Floating-point operations per second: the rate at which a chip does arithmetic. Quoted at a given number format (FP64, BF16, FP8, FP4) and as dense or sparse peak; 1 PFLOPS = 10^15 operations per second. 'FLOPs' (lower-case s) is a count of operations, not a rate. *See also:* [Tensor core](#tensor-core).
## G

- <a id="gpu"></a>**GPU (graphics processing unit)** — A processor with thousands of simple cores that run the same instruction on many pieces of data at once, which suits the matrix multiplications at the heart of neural networks. In this repo 'GPU' usually means the whole package a customer buys (e.g. a B200), which can contain more than one die. *See also:* [Die](#die), [Tensor core](#tensor-core).
## H

- <a id="hbm"></a>**HBM (high-bandwidth memory)** — Stacked DRAM placed millimetres from the GPU on a silicon interposer and connected through a very wide bus, giving terabytes per second of bandwidth. HBM capacity and bandwidth often limit AI performance more than raw compute. *See also:* [CoWoS](#cowos), [Memory wall](#memory-wall).
## M

- <a id="memory-wall"></a>**Memory wall** — The gap between how fast processors compute and how fast memory can feed them data. In LLM inference (especially the decode phase) performance is often bound by memory bandwidth, not FLOPS. *See also:* [HBM (high-bandwidth memory)](#hbm).
## N

- <a id="nvlink"></a>**NVLink** — NVIDIA's proprietary high-speed GPU-to-GPU link used for scale-up. NVLink 5 (Blackwell) provides 1.8 TB/s per GPU, many times a PCIe slot. *See also:* [NVSwitch](#nvswitch), [Scale-up](#scale-up).
- <a id="nvswitch"></a>**NVSwitch** — A switch chip that connects many GPUs' NVLink ports so every GPU can talk to every other at full NVLink speed, forming one scale-up domain (e.g. 72 GPUs in an NVL72 rack). *See also:* [NVLink](#nvlink), [Scale-up](#scale-up).
## R

- <a id="reticle-limit"></a>**Reticle limit** — The maximum area a lithography scanner can expose in one shot (~858 mm² for today's EUV tools), which caps the size of a single die and pushes designers to multi-die packages. *See also:* [Die](#die).
## S

- <a id="scale-across"></a>**Scale-across** — Linking AI clusters in different datacenters (tens to thousands of kilometres apart) so they can work on one job; NVIDIA's Spectrum-XGS targets this. *See also:* [Scale-out](#scale-out).
- <a id="scale-out"></a>**Scale-out** — Connecting many scale-up domains or servers across a datacenter network (InfiniBand or Ethernet) to train or serve at cluster scale. *See also:* [Scale-up](#scale-up), [Scale-across](#scale-across).
- <a id="scale-up"></a>**Scale-up** — Tightly coupling a group of accelerators with a very fast memory-semantic fabric (NVLink, ICI, Infinity Fabric) so they behave like one large GPU. *See also:* [Scale-out](#scale-out), [NVLink](#nvlink).
## T

- <a id="tco"></a>**TCO (total cost of ownership)** — All-in cost of running infrastructure over its life: capital cost (depreciated) plus power, cooling, space, networking, software and operations. In AI it is often normalised to $ per million tokens.
- <a id="tensor-core"></a>**Tensor core** — A specialised unit inside an NVIDIA GPU that multiplies small matrices in one step, delivering most of the GPU's AI throughput. Introduced with Volta (2017). *See also:* [GPU (graphics processing unit)](#gpu), [FLOPS](#flops).
- <a id="token"></a>**Token** — The unit of text a language model reads or writes, roughly three-quarters of an English word. AI economics are increasingly quoted in tokens per second and dollars per million tokens.
